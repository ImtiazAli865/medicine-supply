## Implementation Strategy

1. **MVP first**: Phases 1 and 2, then US1 only. Stop, run its tests, apply the migration to the test project, and try registering from an order. This alone turns typed lines into real medicines safely.
2. **Then US2** (link to an existing medicine) so the duplicate path of US1 has somewhere to go, then US4 (Pending Prices) because it makes lines ready for invoicing, then US3 and US5.
3. **Do not claim anything unrun.** Record real counts only; investigate any intermittent failure; the owner's phone check (T062) and the ADR consent (T063) are not skipped.
4. **Keep the rules in the database.** If a rule matters for integrity (no price overwrite, no auto-link, business isolation), it is enforced in the function or a trigger and tested there, not only in the screen.
